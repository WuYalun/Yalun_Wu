# 个人主页（Starter）

这是为你准备的一个静态个人主页起点，包括 `index.html` 和 `styles.css`。

快速开始
1. 将 `index.html`、`styles.css` 放到仓库根目录（或 `docs/` 目录）。
2. 上传一个头像文件 `profile.jpg`（或在 `index.html` 中替换为你头像的 URL）。
3. 可选：上传 `resume.pdf` 到仓库根目录并修改页面上的链接。

部署到 GitHub Pages
- 方式 A（最简单）：
  1. 将文件放在仓库根目录（或 `docs/`）。
  2. 在 GitHub 仓库中打开 Settings → Pages，选择分支（通常是 `main`）和根目录（/ 或 /docs），保存。
  3. 等待几分钟，你的站点会在 `https://<username>.github.io/<repo>` 可访问（或自定义域）。

- 方式 B（自动化，选择性）：
  使用 `actions-gh-pages` 将 `main` 上的构建结果部署到 `gh-pages` 分支并发布（我可以为你生成 workflow 文件）。

如何自定义
- 修改 `index.html` 中的文本、项目卡片与链接。
- 修改 `styles.css` 中的 CSS 变量（:root）以更改配色、圆角与宽度。
- 想要暗色/亮色切换、动画或更多页面（博客/项目详情），告诉我需求，我可以继续添加。

接下来我可以帮助你：
- 把这些文件直接推到仓库（需要确认我应该提交到哪个分支，以及是否覆盖现有文件）。
- 为你生成 GitHub Action 自动部署配置。
- 替换为你自己的头像、项目列表与社交链接，并预览效果.
